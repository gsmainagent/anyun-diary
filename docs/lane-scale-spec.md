# 泳道非线性压缩 · 需求细化（2026-10-18，未实施）

## 0. 背景（owner 原话归纳）

- 现行 24h 线性泳道：一首 1 分钟的歌在 ~1100px 泳道里只有 ~0.8px 宽，根本点不中；空白（未开播时段）却占掉大半宽度。
- 决定：**泳道放弃时间线性**，压缩空白段，但**保留相对关系**（顺序/节奏/簇内比例）。
- **热力图保持时间线性**（日×时矩阵语义就是"几点在唱"，不能压缩）。
- **场次徽标全删**：录制文件断开 ≠ 多场，"N 场"是误导信息。

| 位置 | 动作 |

## 2. 压缩算法（推荐方案：分段线性 piecewise）

### 2.1 构造（纯函数，输入当日歌曲区间列表 + 泳道像素宽 + 参数）

1. 歌曲按绝对时间排序、重叠合并（复用现状逻辑）
2. **聚簇**：相邻两首歌间隔 < M（默认 10min）→ 同一簇（簇内小间隔保持真实比例，这是"唱歌节奏"的一部分）
3. 簇 [cs, ce] 外扩 P（默认 3min）得活动段，clamp 到日界
4. 活动段之间、日首尾 → **压缩间隙段**

### 2.2 宽度分配：三级刻度 + 压缩比旋钮（owner 2026-10-18 定稿方向）

**旋钮定义（以歌为 1）**：ρ = 每分钟空白宽度 / 每分钟歌宽度（空白被压缩到的比例）。
每分钟宽度：歌 = xs；簇内微间隙 = σ·xs；簇间/日边空白 = ρ·xs。
xs = W / (T歌 + σ·T微 + ρ·T空)（W=泳道宽，T=各段真实时长合计）。

**三级类型**：
| 层 | 段类型 | 每分钟宽 | 允许钳制 |
| --- | --- | --- | --- |
| 1 | 歌块时长 | xs（基准=1） | 歌块有 MINW（可点性），微间隙无 |
| 2 | 簇内微间隙（<M 未聚簇） | σ·xs，默认 σ=1（完全线性，唱歌节奏原样） | **永远不钳制**（比例神圣） |
| 3 | 簇间空白 + 日边空白 | ρ·xs，默认 ρ=0.25 | 可选 minGapPx=6 保底（仅此层） |

**各级内部比例严格保留**：15h:1h:1h 的簇间空白渲染 15:1:1；簇 3h:4h 渲染 3:4；簇内间隙线性。
**退化关系**：ρ=1,σ=1 ⇒ 纯线性；ρ→0 ⇒ 空白全塌缩。σ 可独立下调（如 0.6）对付密集短歌簇，ρ 与 σ 独立可调（owner：簇内外空白比例可以不同）。

**示例**（W=1100px，ρ=0.25,σ=1，T歌+T微=7h、T空=21h）：xs = 1100/(420+315) ≈ 1.49px/min ⇒ 歌 8.9px/min-equivalent、空白 0.37px/min；15h空白→335px、3h簇→269px、1h空白→22px、4h簇→359px。空白间 15:1:1 原样。

- 尺度函数 xAt(t)/tAt(x)：分段线性、严格单调；minGapPx 补足时从其余空白按比例扣回，仍单调。

### 2.2b 压缩感知灰度（owner 2026-10-18 新增功能）

被压缩的空白按**实际压缩倍数**用灰度加深，灰度走**人眼非线性感知校准**（CIE L\* 明度，非线性 sRGB 值直接插值）：

- 灰度编码相对线性（歌）刻度的压缩倍数 c=密度·xs（owner 10:13 定）：无量纲、视口无关、整体缩放不变；固定对数域 [1,256] 映射 L*，图例端点固定 ×1/×256，无需动态计算
- 感知映射：**L\*(c) = 88 − 14·log2(c)**，clamp [40, 88]，再 L\*→sRGB：
  c=1→L*88（近底色，安静）；c=2→74；c=4→60（ρ=0.25 默认档的簇间空白）；c=8→46；c≥16→封顶 L*40
- 用 L\* 而非线性 RGB：同样的压缩倍数差在人眼感知里才是等距（对数↔感知等距的 Weber-Fechner 适配）
- 簇内微间隙 σ=1 ⇒ c=1 ⇒ 与底色同（不打扰节奏阅读）；下调 σ 后自动浮现浅灰
- 旋钮联动：ρ 调小 ⇒ 空白自动变深，灰度即压缩读数；若未来引入分段自适应压缩，每段灰度自然分化
- 暗色主题（墨夜）：L\* 方向翻转（越压缩越亮），基准改 L\*=25+14·log2(c) clamp [25,72]
- hover 空白：tooltip「空 3h12m · 压至 1/4」

### 2.3 可点性保证（核心痛点）

- 歌块视觉最小宽 **MINW=12px**：变换后不足者对称加宽，且不越过相邻块起点（密簇中允许低于 MINW，见 2.5）
- **命中区域 ≥ 视觉宽度 + 两侧各 6px padding，高度 = 整行 40px**（触屏友好）
- 悬停/选中态维持现行 tooltip（歌名/时长/绝对 HH:MM–HH:MM/来源）——**绝对时间信息转移到 tooltip 承载**

### 2.4 刻度与标注（非线性后小时轴不再等距）

- **删掉全局 HourAxis**（compress 模式下），否则刻度会误导
- 每个活动簇：左缘标起始 HH:MM（text-2xs）；簇整体 hover 显示「HH:MM–HH:MM · N 首」
- 间隙段：视觉用 ⋯ 或渐变省略样式；hover 显示「空 3h12m」类时长（平时不显示，减噪）
- linear 模式（兼容开关）保留现行 HourAxis

### 2.5 边界情况

| 情况 | 处理 |
| --- | --- |
| 全天无歌 | StateHint no-data（现状） |
| 连续密集 1 分钟短歌 | MINW 裁剪到邻居起点，允许 < MINW（罕见，可接受，文档注明） |
| 时长未知歌曲 | 按点事件处理：锚定起点渲染 MINW |
| 跨 00:00 | 沿用 shDayStart 日分组（现状） |
| 重叠歌块（同刻多文件） | 复用现状合并；MINW 加宽不越过合并块 |

### 2.6 参数表（初值，集中一处可调）

M=10min（聚簇阈值）/ P=3min（簇边距）/ ρ=0.25（簇间空白压缩比，歌=1）/ σ=1（簇内微间隙压缩比，默认线性）/ minGapPx=6px（仅簇间空白保底）/ MINW=12px（歌块视觉最小宽）/ hitPadding=6px / hit 高=40px / 灰度 L*=88−14·log2(c) clamp[40,88]
